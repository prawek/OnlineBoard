# Online Board

Бесконечная онлайн-доска на Fabric.js. Статический интерфейс размещается на Netlify,
API работает в Netlify Functions (Node.js 24), данные хранятся в Neon PostgreSQL.
Flask, SQLite и отдельный постоянно работающий сервер больше не нужны.

## Развёртывание

1. Создайте проект в [Neon](https://console.neon.tech). Выберите регион рядом с регионом
   функций Netlify. В **Connect** скопируйте **pooled connection string**
   (`postgresql://…-pooler…/neondb?sslmode=require`).
2. Установите Node.js 24. В корне проекта выполните:

   ```powershell
   npm.cmd ci
   Copy-Item .env.example .env
   ```

   В `.env` замените `DATABASE_URL` строкой подключения из Neon, затем выполните:

   ```powershell
   npm.cmd run db:migrate
   ```

   Миграция создаёт таблицы и пустую доску. Повторный запуск сохраняет существующие данные.
   Альтернатива: выполните содержимое `db/schema.sql` в SQL Editor проекта Neon.
3. Загрузите репозиторий в GitHub/GitLab и подключите его через **Import an existing project**
   в Netlify. Настройки уже заданы в `netlify.toml`:

   | Настройка | Значение |
   | --- | --- |
   | Build command | `npm run build` |
   | Publish directory | `dist` |
   | Functions directory | `netlify/functions` |
   | Node.js | `24` |

4. В настройках проекта Netlify добавьте секрет `DATABASE_URL` с областью **Functions**
   и нужным контекстом развёртывания. Запустите deploy. Если секрет добавлен после
   развёртывания, сделайте новый deploy.
5. Откройте `/api/board` на домене сайта: должен вернуться JSON с `schemaVersion: 1`.
   Затем откройте `/` и проверьте сохранение и обновление второй вкладки.

Сборка не подключается к БД и не выполняет миграции. Секрет не попадает в `dist`.
Для Deploy Previews задавайте отдельную БД/ветку Neon, если превью не должно менять
рабочую доску. Загрузка папки через Netlify Drop не заменяет сборку и развёртывание функций.

## Локальный запуск

После настройки `.env` и миграции:

```powershell
npm.cmd run dev
```

Откройте **http://127.0.0.1:5000**. Порт меняется через `PORT` в `.env`.
Локальный сервер использует тот же обработчик API и PostgreSQL, что и Netlify.
Для проверки непосредственно Netlify CLI можно использовать `npx netlify dev`.
В macOS/Linux используйте `npm` вместо `npm.cmd`.

## Перенос старой доски

До перехода экспортируйте доску через **Экспорт → Файл доски JSON**.
После развёртывания откройте этот файл в меню новой доски.
Если старый сервер уже остановлен, получите JSON из SQLite:

```powershell
python scripts/export-sqlite.py instance/board.sqlite3 board-export.json
```

Скрипт только читает SQLite. Оригинал базы сохраните как резервную копию.
Доски больше 4 МБ нужно уменьшить в старом приложении перед импортом.
Локальная очередь старого сайта сама не переносится на новый домен: сначала сохраните
все изменения или экспортируйте их в файл.

## Сохранение и совместная работа

Одна общая доска доступна всем посетителям сайта. Авторизации и отдельных комнат нет:
любой посетитель может изменить и очистить содержимое.

API применяет изменения отдельных объектов в транзакции с блокировкой строки доски.
Повтор запроса после потери ответа не применяет изменение второй раз. Если два человека
редактируют один объект, остаётся последняя принятая сервером версия.

Открытые видимые вкладки проверяют изменения раз в 5 секунд. Скрытые вкладки прекращают
опрос до возвращения пользователя; при восстановлении сети запускается синхронизация.
Ответ `304` сокращает передачу неизменившейся доски. Опрос расходует вызовы Functions
и запросы к Neon даже при отсутствии правок.

IndexedDB и localStorage сохраняют локальную копию и очередь изменений. Можно продолжать
редактирование открытой доски без сети; очередь отправится после подключения.
Сохранение на сервере обозначается индикатором в интерфейсе.

Ограничения: 3000 объектов, 4 МБ JSON на доску, 2 МБ на загружаемое изображение,
40 мегапикселей на изображение. PNG, JPEG, WebP и GIF хранятся внутри JSON.
Размеры выбраны с запасом под [лимиты обычных Netlify Functions](https://docs.netlify.com/build/functions/configuration/).
Большая суммарная доска будет отклонена сервером, изменения останутся локально:
уменьшите содержимое или экспортируйте его в JSON.

Сохраняются рисование, фигуры, текст, стикеры, вставка изображений, отмена/повтор,
копирование, перемещение и масштабирование холста, темы, сетка, экспорт PNG и JSON.
Справка по сочетаниям клавиш доступна в интерфейсе.

## Проверки

```powershell
npm.cmd test
npm.cmd run build
```

Тесты API используют изолированный PostgreSQL-движок PGlite: проверяют SQL, сохранение,
объединение объектов, повторные запросы, откат транзакций, валидацию и HTTP-ответы.
Это не проверка сетевого подключения к Neon или блокировок между настоящими соединениями.

Браузерные регрессии запускают временный сервер с PGlite, рабочая БД не затрагивается:

```powershell
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m unittest discover -s tests -p test_browser.py -v
```

Если Chromium уже установлен, задайте путь к нему через `BROWSER_EXECUTABLE`.
Python нужен только для этих тестов и экспорта старой SQLite.

Документация платформ: [Netlify Functions](https://docs.netlify.com/build/functions/overview/),
[переменные функций](https://docs.netlify.com/build/functions/environment-variables/),
[Node.js и Neon](https://neon.com/docs/guides/node).
