# Online Board

Бесконечная онлайн-доска на Flask, SQLite и Fabric.js. Текст, рисунки, фигуры,
стикеры и изображения сохраняются автоматически. Открытые вкладки получают
изменения через Socket.IO.

## Запуск

Python 3.10 или новее. Из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Доска откроется по адресу **http://127.0.0.1:5000**. В PyCharm можно запускать
`app.py`, выбрав интерпретатор из `.venv`. Node.js и сборка фронтенда не нужны.
Библиотеки браузера находятся в `static/vendor`, поэтому CDN для работы не требуется.

Настройки задаются переменными окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Адрес сервера; `0.0.0.0` для доступа из локальной сети |
| `PORT` | `5000` | Порт HTTP и Socket.IO |
| `BOARD_DATABASE` | `instance/board.sqlite3` | Путь к базе доски |
| `SECRET_KEY` | Случайное значение при запуске | Секрет Flask |
| `FLASK_DEBUG` | Выключен | `1` включает режим разработки |

## Что умеет доска

- Выделение, перемещение, масштабирование и поворот объектов; групповое выделение.
- Карандаш с настройкой цвета и толщины; ластик удаляет объекты целиком.
- Редактируемые надписи и стикеры; прямоугольники, эллипсы и линии.
- Загрузка, перетаскивание и вставка изображений из буфера обмена.
- Отмена и повтор последних 60 действий в текущей вкладке. Набор текста,
  удаление группы, очистка и импорт считаются отдельными действиями.
- Перемещение холста зажатой ПКМ, средней кнопкой, пробелом с мышью или инструментом «Рука».
- Масштаб колесом мыши, кнопками или жестом двумя пальцами; показ всех объектов.
- Копирование, вырезание, вставка и дублирование объектов; вставка обычного текста.
- Светлая и тёмная темы, сетка из точек или линий с сохранением выбора, интерфейс для телефона.
- Экспорт всей доски в PNG и JSON; открытие JSON с подтверждением замены.
- Чистый холст без приветствия и шаблонов, справка по клавишам и индикатор сохранения.

## Сохранение и совместная работа

SQLite хранит одну общую доску для всех посетителей этого сервера. Данные остаются
после перезагрузки страницы и перезапуска приложения. Рабочая база создаётся
автоматически в `instance/` и исключена из Git.

Браузер сохраняет локальную копию и очередь изменений в IndexedDB. Небольшие
изменения также синхронно дублируются в localStorage, чтобы введённый текст
восстановился даже после немедленной перезагрузки. При потере связи можно продолжать
работать в открытой странице; очередь отправится после восстановления соединения.
Открытие приложения с нуля требует доступного сервера.

Сервер применяет изменения к отдельным объектам транзакционно. Повтор одного
запроса после сетевого сбоя не создаёт дубликатов. Отмена собственного действия
сохраняет изменения других объектов от коллег. Если несколько человек меняют
один объект, сохраняется последняя принятая сервером версия. Это совместная
доска без посимвольного объединения текста. Авторизация и отдельные комнаты пока
не реализованы.

Масштаб, положение холста, тема и сетка сохраняются в браузере. История отмены
действует до перезагрузки страницы. Для переносимой резервной копии используйте
«Экспорт → Файл доски JSON».

Ограничения: до 3000 объектов и 20 МБ содержимого на доску; одно изображение
до 5 МБ и 40 мегапикселей. Поддерживаются PNG, JPEG, WebP и GIF. При экспорте
PNG размер ограничен 6000 пикселями по стороне и 16 мегапикселями суммарно;
далёкие друг от друга объекты будут уменьшены, чтобы попасть в изображение.

## Клавиши

| Действие | Сочетание |
| --- | --- |
| Выделение / рука | `V` / `H` |
| Карандаш / текст / стикер | `P` / `T` / `N` |
| Прямоугольник / эллипс / линия | `R` / `O` / `L` |
| Изображение / ластик | `I` / `E` |
| Отменить | `Ctrl+Z` |
| Повторить | `Ctrl+Shift+Z` или `Ctrl+Y` |
| Копировать / вырезать / вставить | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| Дублировать | `Ctrl+D` |
| Выделить всё | `Ctrl+A` |
| Удалить выбранное | `Delete` или `Backspace` |
| Сдвинуть объект | Стрелки; с `Shift` шаг 10 px |
| Вся доска / масштаб 100% | `Shift+1` / `Ctrl+0` |
| Экспорт JSON | `Ctrl+S` |
| Завершить редактирование / снять выделение | `Esc` |
| Справка | `?` |

На macOS вместо `Ctrl` работает `⌘`. Буквенные сочетания привязаны к физическим
клавишам и работают в русской раскладке. Во время ввода текста сочетания доски
не перехватывают обычное редактирование. `Shift` при рисовании фигуры сохраняет
равные стороны, у линии фиксирует угол с шагом 45°.

## Структура

```text
app.py                      # Точка входа для локального запуска
board/
    __init__.py             # Фабрика приложения и Socket.IO
    routes.py               # Страница, HTTP API, уведомления
    repository.py           # SQLite, транзакции, повтор запросов
    validation.py           # Проверка структуры и лимитов
templates/index.html        # Разметка интерфейса
static/
    css/board.css           # Общий стиль, темы, адаптивная вёрстка
    js/
        main.js             # Интерфейс, клавиши, импорт и экспорт
        board.js            # Инструменты и управление Fabric.js
        sticky-note.js      # Редактируемый стикер с внутренними отступами
        document.js         # Изменения объектов и история действий
        sync.js             # Синхронизация и очередь отправки
        storage.js          # IndexedDB, локальное восстановление, настройки
        icons.js            # Единый набор SVG-иконок
    vendor/                 # Локальные библиотеки и их лицензии
tests/
    test_api.py             # Хранение, параллельные записи, проверка API
    test_browser.py         # Пользовательские сценарии в Chromium
instance/                   # Данные приложения; создаётся при запуске
```

## Проверка

Серверные тесты используют стандартный `unittest` и временную базу:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_api.py -v
```

Для браузерных проверок установите зависимости разработки:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_browser.py -v
```

По умолчанию используется Google Chrome по стандартному пути Windows.
Другой путь можно задать через `BROWSER_EXECUTABLE`. Если установленного браузера
нет, выполните `python -m playwright install chromium`: тесты используют Chromium
из Playwright. Браузерный набор сам запускает сервер на порту 5067 с временной
базой; рабочую доску он не меняет. Снимки интерфейса появляются в `test-results/`.
